# Gap ask is product-owned

A **Gap turn** used to paste the live-answer model body, so schema nouns such as validity reached the operator, and a send that did not fill the open gap often repeated the same sentence. We decided the **Gap ask** is product-owned operator wording, keyed by the open gap. The model still extracts terms. It does not own the question.

We rejected model-body passthrough, a jargon filter on model text, and a live-answer call for every Gap kind. Those still leak schema nouns or add a model round-trip to a simple Email vs SMS ask.
