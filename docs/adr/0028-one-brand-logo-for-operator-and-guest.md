# One Brand logo for operator chrome and guest surfaces

**Account & workspace** uploads a single Restaurant **Brand logo**. That blob is the mark on the Owned-location switcher, the Private feedback form header, and guest email chrome. Figma helper copy that treats Workspace logo as operator-internal, plus **Manage guest-facing brand** as a second file, is rejected for v1.

We kept one mark because those surfaces already share one placeholder, `CONTEXT.md` already defines one blob, and a second guest file would split identity before **Brand & guest form** exists. **Manage guest-facing brand** stays an exit to that later Settings child (presentational until it ships). It does not store a second image.
